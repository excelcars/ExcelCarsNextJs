## Intentional differences requiring approval, not automatic restoration

- bcrypt password storage is a security improvement over legacy plaintext passwords and should remain.
- The Next UI’s confirmation dialog for deactivation is an improvement over legacy immediate deletion.
- The Next UI permits changing status during Edit; legacy edit exposes no status control. Retain only if authorization/audit requirements above are implemented.
- The Next list is immediately available and supports server-driven search/filter/pagination, whereas legacy requires Search. This remains an intentional UX improvement, with employee-backed list scope now aligned to legacy.
